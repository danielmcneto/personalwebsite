# Dan's Personal Website

A personal website and portfolio for software and hardware projects.

![Preview Image](assets/preview.png)

## Why?

I created this website to practice web development with HTML and CSS and to showcase my software, hardware, projects, and achievements.

## Built With

* **HTML5** - Page structure and content
* **CSS3** - Styling, animations, and responsive layouts
* **JavaScript** - Theme controls and Spotify status updates
* **Model Viewer** - Interactive 3D model display
* **Lanyard API** - Current Spotify activity and album artwork
* **GitHub Pages** - Hosting and deployment

## Features

* **Spotify integration** - Displays the currently playing song and album artwork through Lanyard
* **Interactive 3D model** - Shows a rotating 3D model with Model Viewer
* **Light mode** - Inverts the website colors with a button
* **Smooth navigation** - Provides fixed navigation with smooth scrolling between sections
* **Project portfolio** - Separates software and hardware projects into dedicated pages
* **Project links** - Links to source code and playable projects
* **Awards timeline** - Presents achievements and awards in a visual timeline
* **Animated background** - Uses rotating decorative background elements
* **Responsive design** - Adapts the layout for desktop and mobile screens
* **Technology showcase** - Displays programming languages, tools, and game engines

## Spotify Requirement

The Spotify widget uses the Lanyard API and requires the associated Discord account to be connected to Lanyard, with Discord activity sharing enabled. A song and album artwork appear only while Spotify is actively playing.
